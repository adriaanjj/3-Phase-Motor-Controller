# 3-Phase-Motor-Controller
This project aims to be an open source 3 phase motor controller with variable frequency

# Current Hardware

 - 1x ESP32
 - 1x BLDC Motor
 - 6x REP30N06LE
 - 1x 100 uF Capacitor
 - 12x M-M Jumper Cables
 - 1x PSU

## Overview
The software will generate a 3 phase output using SPWM. The frequency will be able to be adjusted based on a "throttle" input.
